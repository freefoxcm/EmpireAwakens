# 帝国觉醒：边境守卫

单机 PvE 卡牌守塔原型。选择卡牌后点击战场下方金色虚线范围部署，抵挡波次并击败巨魔。按 1–4 切换卡牌，空格暂停。

## 运行

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址。`npm run build` 用于类型检查和生产构建。

战斗配置和波次位于 `src/battle.ts`；Phaser 画面与 DOM 界面位于 `src/main.ts`。素材来自 `reference_resources`，发布前请确认各素材包的使用许可。

## 战斗与验证

战场的树木、草地、兵营以及单位动画使用现有 Tiny Swords 素材；单位通过两座桥过河，修士会靠近受伤友军进行治疗。双方各有两座自动攻击的防御塔，可被摧毁；战斗单位优先攻击附近敌方单位，其次防御塔，最后主城；修士治疗附近友军，不参与攻击。场上最多部署 10 名友军。敌方主城在巨魔首领被击败前受到护盾保护；护盾挡下的致命伤会在击败首领后结算，解除护盾后摧毁主城，或击败首领和全部波次即可获胜；我方据点被摧毁则失败。点击炮塔可查看射程，点击右上角问号查看规则。

使用 Node.js 24 运行 `npm test`，验证部署、过桥、治疗、防御塔、攻击优先级、Boss 攻击和双方主城胜负判定。战斗数值仍是原型参数，需要结合完整试玩继续调整。

竖版战场使用 480×740 的逻辑坐标，画面按比例缩放；玩家从下方部署，敌人从主城正前方排队出场，再沿左右两路进攻。
