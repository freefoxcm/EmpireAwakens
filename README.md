# 帝国觉醒：战鼓再起

单机 PvE 卡牌守塔游戏。进入游戏后，从征途地图选择已解锁的关卡；点击卡牌并点击战场下方的金色虚线区域部署部队。摧毁任一敌方箭塔或击败指定数量的波次怪物会引出首领；击败首领解除护盾，摧毁敌方主城即可通关。首领召唤物不计入出场击杀数。按 1–4 切换卡牌，空格暂停。

五关依次为边境警戒、密林迷踪、荒野突袭、暗影侵袭和要塞决战；各关有不同的敌人、场景配色与首领技能。通关后解锁下一关，进度保存在当前浏览器；浏览器隐私模式或禁用存储时，进度可能不会保留。

## 运行与验证

```bash
npm install
npm run dev
npm test
npm run balance
npm run build
```

使用 Node.js 24。`npm run balance` 使用固定部署策略比较各关卡的结果和首领出场时机，不能代表真人胜率。浏览器打开终端显示的本地地址。关卡、波次和进度存储定义位于 `src/levels.ts`，战斗模拟位于 `src/battle.ts`，Phaser 战场与 DOM 界面位于 `src/main.ts`。

游戏使用竖版 480×740 逻辑坐标；双方沿两座桥推进，友方弓手和敌方萨满驻守箭塔，守塔角色与箭塔共用生命值。支持点击或触屏选卡部署，手机横屏使用紧凑布局。GitHub Pages 使用仓库工作流部署。

## 战术与成长版本

- 手机使用顶部状态栏、弹性战场和底部操作区。显示投影调整地面与位置，角色、建筑保持等比；逻辑坐标、寻路、射程和触控映射统一。竖屏覆盖窄屏到常见大屏手机，横屏提供右侧操作区。
- 第一关首次有效部署前暂停计时，首次首领说明可确认继续或跳过教学。长按卡牌 350 毫秒或点击详情按钮查看属性；设置、手动暂停、教学和后台暂停相互独立。
- 四兵种定位为低费战士、远程弓手、重装枪骑士、治疗修士。火球于首次通关第一关后解锁，治疗于首次通关第二关后解锁；地图中装备一种，点击技能再点战场施放，切换兵种或 Esc 取消。
- 五关分别有 6/7/8/9/10 组波次，首领半血后进入第二阶段。首领战暂缓普通波次时钟，击败后按剩余间隔继续；召唤物不计入首领触发击杀数。
- 三星条件为获胜、该局主城生命至少 80%、该局两座友方箭塔均存活。保留最高单局星级、最快胜利用时、最高主城剩余比例；失败不覆盖成绩。
- 普通五关全部通关后开放挑战模式：敌方单位生命 ×1.25、伤害 ×1.15、波次间隔 ×0.9，挑战成绩单独保存。四兵种始终可用，没有永久数值升级。
- 存档键升级为 `empire-awakens-progress-v2`，自动迁移 v1 解锁和通关记录并保留旧键。旧通关记为一星，未知用时留空。禁止存储时仍可游玩，会显示无法保存的提示。
- 声音使用本地 CC0 音频素材，由 Web Audio 混音。五首背景音乐自动随机轮播，每轮尽量不重复，场景切换保留当前曲目；默认音乐音量 18%、音效 35%，可分别关闭和调节，首次用户操作后加载。暂停和切后台会停止播放，战斗返回后手动继续。减少动态效果的系统偏好会减少飘字位移。

`src/projection.ts` 管理显示与输入坐标，`src/scene.ts` 管理 Phaser 显示，`src/battle.ts` 管理战斗与法术结算，`src/progress.ts` 管理版本化进度，`src/campaign-ui.ts` 管理地图与结算展示。

`src/audio.ts` 管理音效、独立音量及浏览器解锁，`src/music.ts` 管理循环与配乐切换，`src/audio-events.ts` 将战斗事件映射到声音。素材来源、处理和验收说明见 [音频记录](docs/audio-assets.md)，完整作者与许可清单位于 `public/assets/audio/CREDITS.txt`。

平衡依据与策略结果见 [平衡记录](docs/balance-notes.md)。手机视口模拟和桌面试玩不代替 iPhone Safari 真机对动态地址栏、安全区和触屏的复验。

怪物、场景和 UI 素材来自 `reference_resources` 中的 Tiny Swords 素材包；发布和再分发时应确认各素材包的使用许可。世界地图为参考现有素材风格生成的图像。
