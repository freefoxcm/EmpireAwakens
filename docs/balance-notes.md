# 战斗平衡记录

这些结果来自固定部署策略模拟，只用于版本比较，不代表真人胜率。

## 调整依据

- 原版固定“枪骑士＋修士”可五关主城满血通关，普通第 1/5 关约 67/107 秒。
- 首轮按计划将战士改为 2 费、180 生命、24 伤害，枪骑士为 300 生命、36 伤害，修士为每 1.5 秒治疗 18；五关改为 6/7/8/9/10 组与半血阶段。
- 单纯叠加密集波次和首领导致后两关参考策略全部失败。采用首领战期间暂停普通波次时钟与出兵的节奏，击败首领后按剩余间隔继续，避免积压波次瞬间倾泻。
- 防御塔提供整军时间：友方生命 450、单次伤害 20；敌方生命 400、单次伤害 16；攻击间隔仍为 1.1 秒、射程 125。
- 第五关前 3 组使用哥布林、骷髅、蜘蛛、萨满，后 7 组使用长矛兵、骷髅、豺狼人、萨满。组数、每组 4 人和 14 秒基础间隔保持，先建立防线，再承受混合压制。
- 敌军关卡生命／伤害倍率保持原值；挑战只额外加强敌方单位生命、伤害与波次节奏，不额外增加建筑生命。

## 固定模拟验收

- 普通第三关至少两种参考部署可获胜；第四关火球与治疗均有可行部署；第五关混合火力＋火球约 168 秒、稳健防线＋治疗约 150 秒，均损失过防御塔。
- 固定前排治疗在第四、第五关失败，不能包办五关无损三星。
- 挑战第五关“蓄能反击＋治疗”（先储能、交替枪骑士／弓手／修士）约 197–205 秒可胜，说明后期仍可通过资源时机和组合解决。
- 熟练模拟策略可能在前两关约 60–105 秒提前结束；部分低效策略会超过 180 秒。90–120 / 120–180 秒仍是首关／后续普通关的真人试玩调优目标，没有硬性倒计时。

运行 `npm run balance` 查看普通／挑战、不同策略的实时结果、主城与箭塔损耗、星级、首领出场、部署及施法次数。后续数值改动须保留可通关、多策略和非固定治疗通吃的回归检查。
